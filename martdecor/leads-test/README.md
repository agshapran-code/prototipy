# МАРТдекор — тест заявок

Тестовая форма создаёт только фиксированную вымышленную заявку. Её ID записывается в Google Таблицу и повторяется в Telegram и письме. Столбцы Telegram и Почта показывают результат вызова сервисов. Доставку во входящие проверяют по тому же ID.

1. В тестовой Google Таблице откройте **Расширения → Apps Script** и вставьте Code.gs.
2. В **Настройки проекта → Свойства скрипта** задайте SPREADSHEET_ID, NOTIFICATION_EMAIL, TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID. Используйте личный chat ID получателя, который нажал «Запустить» в боте. Не записывайте значения в GitHub.
3. Выберите **Развернуть → Новое развертывание → Веб-приложение**, выполнение от своего имени, доступ «Только я». Разрешите запрошенный доступ к таблице, исходящим запросам и отправке почты.
4. Откройте полученный URL с окончанием /exec. Нажмите «Отправить тестовую заявку» один раз и сверьте один ID в трёх местах. Пока нет отдельного адреса тестового сайта, это прямая проверка обработчика.
5. Для проверки перехода с прототипа в отдельном тестовом развёртывании задайте адрес /exec в ссылке тестового диалога. Действующая версия GitHub Pages использует основную ветку. Тестовую ветку следует запускать отдельно от неё.
